# Security Policy

## Responsible use

This project is for authorized defensive assessment only. Do not use it against
networks you do not own, administer, or have written authorization to assess.

## Tool behavior

The scanner performs TCP connect checks only. It does not exploit, authenticate,
brute-force, fuzz, send PLC/control payloads, alter systems, or grab banners.

## Reporting a security issue in this tool

Please open a GitHub security advisory or issue with enough detail to reproduce
the problem. Do not include sensitive third-party target data.

## Reporting an actual water/OT cyber incident

Use official channels such as:

- CISA: https://www.cisa.gov/report
- EPA Water Cybersecurity: https://www.epa.gov/cyberwater
- FBI IC3: https://www.ic3.gov/
- WaterISAC: https://www.waterisac.org/contact
